# OpenBridge Command Menu – HELIO Extension Element

Hand-written (not generated by `create-element.mjs`, which only covers
instruments, indicators and automation). Combines two OpenBridge components:

- `<obc-command-button>` – icon button showing the command state
  (`obi-command-in` / `obi-command-no`).
- `<obc-command-menu>` – card with the command status, description, location
  and a slide-to-take / slide-to-release switch (`obc-start-stop-switch`).

Typings: `node_modules/@oicl/openbridge-webcomponents/dist/components/command-menu/command-menu.d.ts`
and `.../command-button/command-button.d.ts`.

## Files

```
src/components/CommandMenu.tsx
src/components/CommandMenu.stories.tsx
src/elements/CommandMenuElement.tsx      (export `commandMenuElement`)
```

Sizing: **intrinsic** – natural size, centered in the container.

## Modes

- `button` (default): the command button; clicking it opens the menu as a
  popover (`softDismiss`, wired with OpenBridge's `bindPopoverTrigger`). The
  popover sits in the browser's top layer, so HELIO containers with
  `overflow: hidden` do not clip it. It is placed below the button (above when
  there is no room), kept inside the window, and closes on a click outside,
  `Escape`, a second click on the button or a window resize. The dismiss cover
  normally starts below the OpenBridge top bar; there is none in HELIO, so the
  component sets `--topbar-height: 0px`.
- `menu`: the menu card itself, always visible.

## Command state

`inCommand` is read from the DP and written back when the user slides the
switch; the `onChange` action runs afterwards. The switch flips itself
immediately. If `inCommand` has not followed the request within 2 s (e.g. a
static value, a read-only variable or a rejected write), the menu and switch
are reset to the DP value. In `PreviewEdit` the button does not open the menu
and the card ignores input.

## Properties

| Key              | IDE label                                            | Kind                      | Group       | obc target                               |
| ---------------- | ---------------------------------------------------- | ------------------------- | ----------- | ---------------------------------------- |
| `inCommand`      | In command (written on toggle)                       | DP Boolean, Data variable | Values      | `inCommand` (menu and button)            |
| `status`         | Status (e.g. Joystick)                               | DP String opt             | Values      | slot `command-status`                    |
| `description`    | Description (e.g. DP)                                | DP String opt             | Values      | slot `command-description`               |
| `location`       | Location (e.g. Aft Bridge)                           | DP String opt             | Values      | slot `command-location`, `showLocation`  |
| `takeLabel`      | Take command action (default Take)                   | DP String opt             | Labels      | slot `toogle-action-to-in-command-label` |
| `releaseLabel`   | Release command action (default Release)             | DP String opt             | Labels      | slot `toogle-action-to-no-command-label` |
| `inCommandLabel` | In command state (default In CMD)                    | DP String opt             | Labels      | slot `toogle-state-in-command-label`     |
| `noCommandLabel` | No command state (default No CMD)                    | DP String opt             | Labels      | slot `toogle-state-no-command-label`     |
| `mode`           | Mode (button opens the menu, menu is always visible) | Enum `button` \| `menu`   | Display     | –                                        |
| `icon`           | Icon (auto = command state)                          | Enum                      | Display     | slot `command-icon`                      |
| `onChange`       | On change (after writing In command)                 | Action opt                | Interaction | `change` event                           |

`icon` options: `auto` (in/no command icon), `joystick`, `autopilot`,
`autoTrack`, `mainEngine`, `azimuthThruster`, `tunnelThruster`, `rudder`,
`none`. The location (and its divider) is hidden when `location` is empty.
