Generated by `scripts/create-element.mjs` from `<obc-gauge-radial>`. Shared patterns
(CSS import, AutoSizer, value mapping, DP resolution, pitfalls) are described
in [openbridge-compass.md](./openbridge-compass.md).

- OpenBridge docs: <https://openbridge-storybook.web.app/?path=/docs/instruments-gauge-radial--docs>

```
src/components/RadialGauge.tsx

src/elements/RadialGaugeElement.tsx      (export `radialGaugeElement`)
```

Sizing: **square** (largest square that fits the container).
Main value: `value` – required, and the instrument shows `loading` while it is unreadable.

Unset optional props are **not passed** to the web component, so its own
defaults apply (the React wrapper would otherwise overwrite them with
`undefined`).
